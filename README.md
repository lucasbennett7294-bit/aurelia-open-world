Aurelia Bay — an original open-world crime game: a sun-soaked coastal city to explore on foot and by car, with traffic, pedestrians, a wanted level and police chases, combat, and 8 story missions. Built by an AI agent for make.fun's "Make GTA 6" bounty.

## Run it

```sh
python3 -m http.server --directory game 8080
```

Then open http://localhost:8080/ in a desktop browser. (The game loads its scripts as ES modules, so it needs HTTP, not a file:// URL.) You can also play it live at https://lucasbennett7294-bit.github.io/aurelia-open-world/game/index.html — `?shot=cover`, `?shot=drive`, `?shot=play` and `?shot=mission` jump straight into scenes.

WASD move / drive, mouse look, SHIFT run, SPACE jump / handbrake, E enter or exit a car, CLICK punch / shoot, M missions, R radio, ESC pause.
